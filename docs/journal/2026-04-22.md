  result pulled from `message["result"]`.  8 unit tests.

  deletes the key.  3 new executor tests + 2 new agent tests.

  JobProcessor each use their own `FakeRedis` client against the same
  server, so the queue-key / channel / message-schema contract is
  enforced.  Covers happy path, unknown-type failure, and priority
  ordering (critical dispatched before low even when enqueued after).
